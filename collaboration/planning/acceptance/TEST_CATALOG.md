# 统一验收用例库

版本：v1.1｜32个用例定义，当前没有因此新增任何通过结果。

每例分别记录 Airtable / Microsoft 的实际结果。时间使用带时区时间戳，固定样本日期用于可重复测试；真实运行按规则时区计算。历史生产样本只读快照与合成数据分开；用合成数据复现不得改动同名生产项目。

规划文档中链接的用例是接手者必须证明的结果。Not Run 与 Fail 分开；单元测试、页面JSON、手工数字不能替代平台行为。
