## 1. 匹配规则

1. 正式项目编号以周报／All Tracker 为准。先确定正式编号范围，再用 **SKU＋工厂** 唯一定位实际记录。同一个 SKU 在不同工厂是不同管理单元。
2. Airtable 的 X 开头自编编号不作为正式编号。若一条 X 记录尚无正式编号，只有其 SKU、工厂完全一致且候选唯一时，才在预览中建议回填 `Project Number (Manual)`；保留 X 编号、记录 ID 和已有链接。
3. 已绑定另一个正式编号的记录不自动改绑；重名、仅 SKU 相同、仅项目名称相似都不能作为匹配依据。
4. 周报同一编号可以有多个区块，不能提前删除；每个区块分别核对 SKU 和工厂。周报列多个 SKU 时，逐个匹配独立记录；不能把部分 SKU 的进展覆盖到一条合并多个 SKU 的旧记录。
5. 工厂允许精确名称、已保存的代码／ID、精确“名称＋代码”或明确配置的别名。没有依据的后缀删除、模糊名称猜测不自动启用。工厂重名时仍需确认具体记录。
6. 无唯一结果、SKU 或工厂缺失、目标包含多个 SKU／工厂、同一目标被重复命中：提示并跳过相应内容，不新建项目来掩盖问题。

## 2. 重要信息的去向

| 来源 | 写入规则 |
|---|---|
| Current Progress | Engineering remark(Manual)；保留人工备注与历史，追加本次进展。正文不变时只推进日期，不重复正文。 |
| Eng Update This Week | Current stage；保留全文，不压缩成 EB／MP 等单个阶段。 |
| LOA-13weeks plan | 对应 LOA 字段，保留全文。 |
| Jira 计数 | Jira summary；0 是有效数值，缺失计数保留已有值；非法数字或无法安全合并的旧文字给出提示。 |
| 时间线 | Tasks，日期只写 Due Date；不推算开始日期或工期。匹配白名单里程碑；白名单外有效任务仍导入，里程碑留空。 |
| CN／VN 等里程碑后缀 | 对应主里程碑；同一主里程碑地区日期一致时合并，不一致时停止该里程碑。CAD／BUILD、Last P／Last P BUILD、新 MP／Previous MP 分开。 |
| 新任务负责人、绿色完成 | 新任务继承 NPI Owner；绿色完成按实际任务负责人填写 Completed By。人员不唯一时提示，不乱填。 |
| Next PLM | 稳定匹配已有 Next PLM 任务，或新增一条；提取明确日期，新任务继承 NPI Owner。 |
| First CRD | 明确日期优先；缺失／TBC 时按明确 MP 日期减 45 个自然日；原日期冲突或作废时不推算。 |
| Key Issues | Issues 的描述、行动、负责人、风险和日期；既有问题保留记录 ID 和首次记录日期；不能因周报未提及就关闭问题。 |

Region、Sub Category、Capacity 按你原始要求不恢复为默认导入项。Airtable 的 Last Modified 是只读系统字段，不能把历史周报日期硬写进去；周报日期用备注中的日期记录保护新旧版本。

当前简洁备注格式没有结束标记：人工直接追加在最后一个日期块后的文字，会被视为该块正文；脚本保留原文，不猜测哪些句子属于单独的人工批注。

## 3. 总表导出与回写

- Airtable → All Tracker：读取当前云端值，按上述身份匹配，导出**新副本**；保留原文件、公式和未映射列。云端没有周报日期块时可以建立快照基线，但读取日期不会伪装成总表的周报日期。
- All Tracker → Airtable：使用导出时一同生成的 `.xlsx.autopm.json`，比较“导出原值、本地现值、云端现值”。只处理本地实际改过且目标唯一的字段。改完后需保留这个同名文件。
- 空白、删除列、公式不清空云端。双方同时改同一字段、身份或映射变化、预览后文件变化，均停止回写。
- 回写只更新基线中明确绑定的现有记录；新增行／新任务不凭空创建。总表没有列承载的 Issue 明细、普通任务，不会塞入其他列；详情留在 Airtable 与审核记录中。

## 5. 审核后的操作入口

1. 在本目录运行 `启动源码版.cmd`，选周报，生成预览，查看未写入提示后再执行同步。
2. 进入“本地总表”，选择原始 All Tracker，选择“Airtable → All Tracker”，预览后导出副本。
3. 编辑副本，保留旁边的同名 `.autopm.json`；选择“All Tracker → Airtable”，审核差异后执行回写。

原始 `All Tracker 审核副本.xlsx` 及其同名基线文件用于审核，但含真实业务数据，未上传 GitHub。当前未获批准的工厂和合并记录仍然被排除。
