AutoPMAIRTABLE TOKEN HELPER
安装与首次配置
CHROME / EDGE

从这里完成第一次连接。

没有 Client ID 可以先用 PAT；OAuth 集成可按以下步骤注册。

01

加载浏览器扩展

  1. 解压安装包到固定目录。
  2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 打开“开发者模式”→“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
  4. 点击工具栏中的扩展图标，打开授权助手。
02

立即使用：创建 PAT

  1. 在插件选择“AutoPM 周报同步”，保持“PAT 创建 / 导入”。
  2. 打开 Airtable Token 管理页，创建 Token。
  3. 按插件清单添加 scopes：data.records:read、data.records:write、schema.bases:read。
  4. 添加目标 Base / 工作区，保存后复制完整 Token 到插件验证。

PAT 权限必须在官方页面保存。插件中修改勾选不会直接修改 PAT。PAT 未返回完整 scopes 时，插件会显示“未知”。

03

自动授权：首次配置 OAuth

  1. 插件切换为“OAuth 自动授权”，打开 OAuth 集成管理，点击 Register new OAuth integration。
  2. 填写名称，将插件显示的回调地址复制到 OAuth redirect URI。
  3. 启用需要的 Permission scopes，保存。公开客户端不要生成 Client Secret。
  4. 复制 Client ID 到插件，点击授权，在 Airtable 官方页面选择可访问的 Base / 工作区。
  5. 给其他账户使用前，在集成中填写支持邮箱、公开隐私政策及服务条款网址。

改变 OAuth 权限后，点击“应用所选权限”。减少权限会刷新 Token，增加权限会重新打开授权页。

04

验证并交给 AutoPM

  1. 获取 Base 列表 → 选择目标 → 读取表结构。
  2. 核对 Projects、Tasks、Issues 表 ID，点击“验证 Projects 记录读取”。
  3. 导出 JSON，在 AutoPM“连接设置”中导入并保存。

OAuth Token 会过期，刷新后之前导出的配置也会失效。AutoPM 当前不会自动刷新 OAuth，长期连接建议使用 PAT。

验证只读取数据，不执行写入。读取成功不能证明写入权限。Token 保存在浏览器会话中，浏览器会话结束后需重新连接。JSON 包含完整访问令牌，请妥善保存。

默认周报同步权限：读取记录、写入记录、读取表结构完整说明 · 隐私说明
