# 隐私与数据处理

本扩展直接连接 Airtable 官方 API 与授权服务。没有分析统计、广告、遥测或第三方代理服务器。不读取网页 Cookie、浏览历史、其他页面内容或用户密码。

完整访问令牌、OAuth 刷新令牌与 PKCE 临时信息保存在浏览器的扩展会话存储中，只允许可信扩展上下文访问。用户主动点击时才显示、复制或导出访问令牌。令牌不写入浏览器同步存储。Client ID、所选 scopes、Base ID 保存在本机持久设置。

用于连接验证的数据：Airtable 用户 ID、可访问 Base 的名称 / ID / 角色、表名称与 ID。记录读取探测最多请求一条记录，扩展后台仅返回数量，不把记录内容传至界面、不持久保存记录内容。

“清除本机令牌”清除当前浏览器会话中的密钥。已导出的 JSON、已复制到剪贴板的内容需由用户另行管理。Airtable 服务端授权需要通过官方管理页撤销。

扩展权限用途：storage 保存设置与会话；identity 打开 OAuth 授权及接收回调；clipboardWrite 响应用户点击复制。网络权限限 Airtable 官方站点及 API。无 content scripts、cookies、history 或全站权限。

本说明适用于提供的源代码与发行包。若自行修改、上架或运营集成，应同步更新隐私政策并提供运营方的联系方式。
