# Agileex主路线判断决策

**决策日期**: 2026-05-28
**决策人**: Sunny

## 核心判断
选择Agileex作为AutoPM主合作路线，Rodyr作为备选/技术顾问角色

## 选择Agileex的理由
1. **微软生态契合**: 与SharkNinja现有IT栈（SharePoint/Teams/Oracle ERP）高度兼容，集成成本低
2. **已有合作基础**: 正在公司内部执行CAT/VAVE Power Apps项目，有成熟的交付能力和信任基础
3. **Jen主动引导**: Biling（SN采购）主动安排对接，Jen明确支持此路线，审批路径顺畅
4. **短期可落地**: Phase 1可在4-6周交付基础可用系统，无需等待NDA审批
5. **风险可控**: 公司规模130+人，有10年Power Platform经验，客户案例覆盖制造业

## Rodyr作为备选的原因
1. **NDA硬约束**: 当前NDA禁止直接集成Ody平台，短期内无法推进核心功能
2. **公司早期风险**: 2025年成立，仅2-3人团队，交付能力和持续运营风险高
3. **无企业集成经验**: 未接触过Oracle ERP/SharePoint等大型企业系统集成
4. **潜在价值**: 自研RAG+知识图谱技术可作为AI架构参考，适合技术顾问角色

## 后续行动
1. 与Agileex沟通Phase 1需求，获取POC方案（交付物/时间/预算）
2. 确认Rodyr NDA进度，评估AI架构顾问合作模式
3. 下周二向Jen汇报此路线决策及推进计划
