# 网易智企帝王蟹（ClawHive）AI员工平台
## 核心信息
- **发布时间**：2026-05-29（2026网易创新企业大会）
- **定位**：企业级AI Agent管理平台，本质是AI员工的"HR系统"
- **解决的五大断层**：
  1. **知识断层**：通用智能≠理解企业，AI缺乏企业知识库支撑
  2. **数据断层**：有数据≠AI用得上
  3. **流程断层**：单点效率≠端到端产出
  4. **治理断层**：无边界≠敢放手，缺安全机制
  5. **价值断层**：无法验证≠持续投入，缺量化标准

## 四大AI员工场景
- **销售AI员工**：复制销冠经验，做客户记录、对练、作战方案
- **私域AI员工**：千人千面运营话术，从规模触达到精细化经营
- **应用交付AI员工（CodeWave SSD）**：规格驱动开发，先翻译需求成标准化规格再生成代码
- **安全治理**：事前事中事后全链路管控

## 管理闭环（类HR）
- 接入（招聘）→ 编排（定岗）→ 治理（合规）→ 运营（考核/淘汰）

## 阮良的三个预测
1. AI员工将成为企业标配，内嵌业务流程
2. AI治理上升到CEO层面议题
3. 各行各业将涌现第一批"AI原生企业"

# CodeWave SDD（Spec-Driven Development）平台
## 核心信息
- **发布时间**：2026-05-11
- **定位**：企业级AI Coding平台，核心思路是"先想清楚再动手"——AI写代码之前，先把需求翻译成标准化规格（Spec），人确认后再生成代码

## 三位一体架构
1. **NASL**（NetEase Application Specification Language）：网易自研DSL，强类型+静态检查，锁定技术栈，杜绝框架漂移和风格混乱
2. **SDD**（Spec-Driven Development）：标准化Spec替代自由Prompt，需求→设计→任务→代码全流程规范化
3. **可视化平台**：创建/开发/测试/部署一站式，五大设计器（页面/逻辑/数据/查询/流程）

## 四步标准流程
1. **智能解析PRD**：自动解析文档、流程图、原型图，提取布局/功能/交互
2. **规范需求拆解**：AI识别歧义与冲突，输出标准化Spec，作为人机契约
3. **技术设计确认**：自动输出架构、数据建模、组件、UI规范，确认后才编码
4. **云端执行与交付**：AI云端生成代码，可预览可部署，增量需求走同样流程

## 解决的企业痛点
- Vibe Coding输出不稳定 → Spec约束可控
- 技术栈"漂移" → NASL统一DSL，自动输出Vue/React+Spring合规代码
- 缺架构约束 → 强类型系统+静态检查
- 缺工程管理 → 全生命周期覆盖
- 资产无法沉淀 → 组件/模板/逻辑自动沉淀，跨项目复用

## 效率数据
- 150个功能点的中型项目：传统2-3人需15天 → CodeWave 3-5天
- ISV并行项目数提升2倍，架构精简+人力下降，利润结构优化

## 与Copilot/Cursor的差异
Copilot/Cursor侧重个人提效，缺企业级约束和资产管理；CodeWave面向企业工程化交付，Spec锁定规范，资产沉淀复用。支持私有化部署和混合云。
