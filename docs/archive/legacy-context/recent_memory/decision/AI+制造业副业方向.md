# AI+制造业副业方向决策（2026-05-30）

## 核心定位
Sunny的副业核心是利用"制造业深度×AI实践×CTO视野"的交叉能力，为中小制造企业、外贸公司提供AI工具代建服务，帮助他们将业务知识转化为可落地的AI工具。

## 目标客户
- 中国数百万中小制造企业、外贸公司、工厂老板
- 他们听说AI能降本增效，但完全不知道从哪下手
- 不需要大模型和技术原理，需要直接能用的AI工具

## 服务内容
- AI工具代建：定制开发企业级AI Bot（基于Coze平台）
- AI+制造业培训：带着制造业场景教AI应用（如用AI做项目管理系统、认证知识AI化）
- AI咨询：为企业提供AI落地的整体方案

## 行动路径
1. **短期（6周内）**：接到第一个AI工具代建单子，交付并拿到案例
2. **中期**：积累5-10个案例，建立个人品牌
3. **长期**：将服务产品化，打造AI+制造业的标准化解决方案

## 关键优势
- 懂制造业底层（能拆能修能改，真实工程经验）
- 亲手搭过AI工具落地（AutoPM、NPI流程AI助手等）
- 有CTO课程的系统视角
